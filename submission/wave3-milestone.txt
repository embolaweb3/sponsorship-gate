Wave 3: Preprod, a running sponsor service, and hardening.

Delivered in Wave 2 and therefore no longer on this list: local deployment, the two-party sponsored flow, the sponsor-side transaction inspector, integration-layer abuse tests (including a sponsor with no DUST), reproducible setup instructions, and a pinned devnet stack.

- Deploy Sponsorship Gate to Midnight Preprod and run the same register/authorize flow with real proofs and block confirmations. This is the project's first LIVE-network evidence. Needs a funded Preprod wallet; `TARGET=preprod npm run flow` already targets it.
- Ship a reference sponsor service as long-running code around `inspectCandidate`: per-pool budgets, rate limits, structured refusal logs, health checks.
- Epoch-partitioned nullifiers, so `spentNullifiers` stops growing without bound, with a documented and tested pruning policy.
- A browser wallet (DApp connector) in the console, so it can drive a live pool and not only the in-browser sandbox.
- Surface a minimum-anonymity-set policy in the console and the sponsor service, since the anonymity set is the pool's size.
- An independent review of the contract and the inspector.
